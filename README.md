# my-online-cv

Personal online CV and portfolio built with Next.js, three.js, and Framer Motion.

## Phase 1

- Next.js app with three.js and Framer Motion
- Content `Container` for CV details
- Fixed digital white-space background

## Phase 2

- Three blank Jarvis consoles (`Identity`, `Experience`, `Systems`)
- One-section-per-scroll snap navigation
- HUD boot transitions and tablet/mobile layout clamps

## Phase 2.1

- Consoles sit in a 3D space with a new random layout on every page load
- Scroll flies the camera through the void from one console to the next

## Phase 2.2

- Each console sits in a 3D brushed-metal chassis
- Camera travel uses a smooth ease-in instead of a snap

## Phase 2.3

- Particle boot sequence with hover interface
- Splash zoom transition into a 3D Jarvis identity console
- Console includes an image block and a details block
